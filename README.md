# Computer Forensics Game

This repository now contains two static builds of **The Ghost of Harlow Hall**:

- `ghost-of-harlow-hall-v2/` — the new recommended version with login, tutorial, smartphone HUD, certificate generation, and Web Audio effects
- `ghost-of-harlow-hall/` — the original v1 release kept for reference

## Recommended launch target

Open or deploy:

```text
ghost-of-harlow-hall-v2/index.html
```

The project remains a static HTML/CSS/JavaScript experience that is suitable for GitHub Pages.
